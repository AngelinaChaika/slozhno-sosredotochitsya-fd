# Учебный проект: Сложно сосредоточиться

Учебный фронтенд-проект, выполненный в рамках обучения.
Проект представляет собой адаптивную страницу с поддержкой светлой и тёмной темы.

---

## Описание проекта

Проект выполнен с использованием подхода mobile-first.
Реализованы три версии интерфейса:

- мобильная (375x668px)
- планшетная (768x1024px)
- десктопная (1024x768px)

Также реализовано переключение между светлой и тёмной темами с использованием CSS-переменных.

---

## Используемые технологии

- HTML5 (семантическая разметка)
- CSS3
  - Grid Layout
  - CSS Variables
  - Media Queries
- Методология БЭМ
- Mobile First
- Git / GitHub
